\# LexRO



AI assistant for Romanian legislation. Ask questions about your rights and obligations under Romanian law (Codul Muncii, Codul Civil, Codul Fiscal, etc.) and get clear answers with verified citations to the exact article in the source law.



Portfolio project combining Python (RAG pipeline) and Java (Spring Boot web app).



\## Status



Early development — scaffolding phase.



\## Structure



\- `AI-Module/` — Python / FastAPI service (RAG pipeline, embeddings, retrieval, LLM)

\- `BackEnd/lexro-api/` — Java / Spring Boot web app (UI, auth, chat history)



\## Disclaimer



Educational and informational tool only. Not legal advice. Consult a lawyer for important decisions.
